Серьёзных поломок нет.

Поиск `site:pldpolymer.com` и запрос по марке (ENGAGE 8150) не вернули ни одной страницы сайта (одно проверенное наблюдение, не доказательство отсутствия в индексе); из CONTEXT.md: 12 поисковых визитов за месяц. Контент-архитектура (категория вместо грейда) не обслуживает запросы по маркам.
- **Индексация:** подтверждённых технических блокеров нет (robots открыт, noindex только на заглушках `products/*`, которых нет в sitemap). Признаки слабой индексации/видимости — по косвенным данным; точный статус — только через GSC/Вебмастер.

# Дополнение 4: решение владельца и доработка страниц EVOH (19.10.2026)
- **Решение:** TDS и цены **только по запросу на email**, на сайте не публикуются (защита от злоупотребления).
