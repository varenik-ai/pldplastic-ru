# Аудит pldpolymer.com — 19.10.2026

Метод: собственный HTTP-краулер по всем 74 URL из sitemap + curl-проверки + анализ исходников репозитория + 2 поисковых запроса. **Не проверено** (нет доступа): Google Search Console, Яндекс Вебмастер, Метрика/GA4, данные Core Web Vitals (field), Lighthouse, ссылочные сервисы, Wordstat/Keyword Planner. Всё, что зависит от них, помечено «требует проверки».

## 0. Ответы на ключевые вопросы
- **Состояние:** технически рабочий статический сайт: 74/74 URL из sitemap отдают 200, HTTPS (Let's Encrypt до 26.11.2026), http/www → 301 на https://pldpolymer.com/, настоящий 404, gzip, canonical на каждой странице, нет дублей Title/Description, у каждой страницы ровно один H1. Серьёзных поломок нет.
- **Топ-3 к исправлению:** (1) нет страниц отдельных грейдов и нет TDS/PDF — страницы продуктов это одна общая страница на полимер с таблицей; (2) заявленные марки Dow/LG/SK и разметка `manufacturer` = Jiangsu Pulide создают риск неверных утверждений о статусе (см. §9); (3) форма не измеряется (нет событий GA/Метрики) и не квалифицирует лид.
- **Что сильнее всего ограничивает рост:** домен без видимости. Поиск `site:pldpolymer.com` и запрос по марке (ENGAGE 8150) не вернули ни одной страницы сайта (одно проверенное наблюдение, не доказательство отсутствия в индексе); из CONTEXT.md: 12 поисковых визитов за месяц. Контент-архитектура (категория вместо грейда) не обслуживает запросы по маркам.
- **Индексация:** подтверждённых технических блокеров нет (robots открыт, noindex только на заглушках `products/*`, которых нет в sitemap). Признаки слабой индексации/видимости — по косвенным данным; точный статус — только через GSC/Вебмастер.
- **Страницы грейдов:** отдельных нет. Есть таблицы марок внутри страницы категории (POE: ~25 строк Dow ENGAGE с плотностью/ПТР/твёрдостью, без ссылок на TDS).
- **Дубли RU/EN, между доменами:** RU и EN — разные URL, hreflang есть (кроме мелочей ниже), это нормальные версии, а не дубли. `pldpolymer.ru` **не резолвится** (нет A/NS-записей), так что конкуренции доменов нет.
- **Что мешает запросу:** нет выбора марки/объёма/страны в форме, нет ссылок на TDS у марок, нет телефона, нет событий-целей, контакт — email + WeChat.
- **Что улучшит качество лидов:** форма с полями «материал/марка, объём, страна, нужен TDS», страницы марок с источниками, события конверсии.

## 3. robots.txt и sitemap
- robots.txt: `Allow: /`, ссылка на `https://pldpolymer.com/sitemap.xml` (200). Ресурсы не блокируются. Менять не нужно.
- sitemap.xml: один файл, 74 URL — sitemap index не требуется. `lastmod` у части страниц 2026-08/09 — проверить, что обновляется при правках (статический хостинг, правится вручную).
- Старые URL: `products/<x>/` отдают 200 с noindex и meta refresh на `product-<x>.html` — корректно для статики, но meta refresh слабее 301; в sitemap их нет.
- Требует проверки: GSC «Страницы» — сколько из 74 проиндексировано.

## 6. Доверие, бренды и разметка
- Сайт позиционируется как сама компания (по CONTEXT.md). На странице POE при этом заголовок «Dow — ENGAGE™ POE» и описание «ENGAGE Dow, LG Lucene, SK». **Риск (требует подтверждения владельцем):** без договора с Dow/LG/SK это может читаться как заявление об авторизованной поставке или производстве. Нужны: либо документ/статус, либо нейтральная формулировка «марки-аналоги/эквиваленты, подбор по запросу».
- JSON-LD на 42 страницах продуктов: `Thing` + `brand: SUPULIDE` + `manufacturer: Jiangsu Pulide Plastic Co., Ltd.` — для продукта Dow это неверно, если компания не производитель этой марки. Рекомендация: убрать `manufacturer` или заменить на `provider/seller` (Organization), не добавлять Product без цены/наличия.
- About: «производитель» встречается 1 раз — проверить контекст на соответствие статусу (поставщик/трейдер).
- Нет: юридических реквизитов, политики конфиденциальности (проверить в футере), условий поставки/оплаты, сертификатов, ссылок на документы.
